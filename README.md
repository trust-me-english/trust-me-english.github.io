# trust-me-english-site

Public pages for Trust Me English, served by GitHub Pages:

- `privacy.html`: Privacy Policy (English, legally binding version).
- `privacy.ru.html`: Russian translation.
- `terms.html`: Terms of Service (English).
- `index.html`: a minimal landing page linking to them.

Plain HTML and one stylesheet, no build step.

## Publishing

The repository is `trust-me-english/trust-me-english.github.io` on GitHub, served by GitHub Pages from `main`, folder `/ (root)`:

- https://trust-me-english.github.io/privacy.html
- https://trust-me-english.github.io/privacy.ru.html
- https://trust-me-english.github.io/terms.html

The privacy policy and terms URLs go to App Store Connect, TikTok for Developers and Meta for Developers.
